Complete Setup Guide

1

Create a Google Cloud Project

First, you need to set up a project on Google Cloud to get your credentials.

Follow these steps:

  1. Go to Google Cloud Console
  2. Click "Create Project" and name it "Auto Gmail Replier"
  3. Wait for the project to be created (1-2 minutes)
  4. In the search bar, search for "Gmail API"
  5. Click "Gmail API" and press the "Enable" button

The Gmail API is free. This just lets the app access your emails.

2

Get Your Client ID

Now you need to create OAuth credentials to connect your Gmail account.

Follow these steps:

  1. Go back to Google Cloud Console
  2. Click on "Credentials" in the left menu
  3. Click "Create Credentials" → "OAuth Client ID"
  4. Select "Web application"
  5. Under "Authorized redirect URIs", add: https://nipecio.github.io/Invoice/index4_merged.html
  6. Click "Create" and copy your "Client ID" (looks like: 123456-abc.apps.googleusercontent.com)

You'll need this Client ID in the next step.

3

Add as Test User (First Time Only)

Since the app is in development, you need to add your Gmail as a test user.

Follow these steps:

  1. In Google Cloud Console, click "OAuth consent screen"
  2. Scroll down to "Test users"
  3. Click "Add Users" and enter your Gmail address
  4. Click "Save"

This only takes 30 seconds and only needs to be done once!
